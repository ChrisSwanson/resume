## Which variant each sign uses (pass 5)

The signs are built into the buildings (`render/logos.py`: facade relief, roof-edge letters, roof or
roof inlay). Each uses an official file unmodified; nothing is cropped, thickened or redrawn.
- Palantir: no official emblem-only file was found (the site's icon logo is the same lockup), so the roof letters use the full lockup.
- Wells Fargo: the box logo exists only as PNG, so the stone fascia carries the official one-line wordmark.
- Norwich: the header SVG and the footer SVG are the same lockup; there is no official shield-only vector, so the full lockup stands as upright letters on the parapet of the long front hall on the avenue (90 m wide, so its serif wordmark clears the 2 px stroke floor at 1440 wide).
